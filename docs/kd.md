# Дистилляция: подбор α и T (шаг 5)

KD-лосс: `α·CE(y, z_s) + (1−α)·T²·KL(softmax(z_t/T) ‖ softmax(z_s/T))`
(`kd/trainer.py::KDObjective`). Включается в `train.py` флагом `--teacher_task_id`
(без значения — обученный ResNet-50 шага 2), параметры — `--kd_alpha`, `--kd_temperature`.
Логиты учителя на аугментированных батчах считаются один раз в кэш
`<output_dir>/teacher_cache` (`kd/teacher_cache.py`).

## Сетка: родительская задача и подзадачи

`scripts/kd_grid.py` — ClearML `HyperParameterOptimizer` + `GridSearch`, та же схема,
что у подбора ёмкости (`scripts/capacity_search.py`):
- **контроллер** — родительская задача `kd-grid-w32-c2` (тип optimizer);
- **точка сетки** (α, T) — дочерняя задача, клон базовой задачи `train.py`;
- исполняет их clearml-agent в Colab (`colab/agent.ipynb`, очередь `colab-t4`), по одной;
- код агент берёт из GitHub, ветка `parallel-runs` — изменения должны быть запушены.

| Параметр | Значение по умолчанию |
|---|---|
| α | 0.1, 0.5, 0.9 |
| T | 2, 4, 8 |
| ученик | w32/c2 (`--cnn_width 32 --cnn_convs_per_stage 2`) |
| запусков на точку | 2 (`--n_runs 2 --parallel_runs 2`), `--init_seed 0 --seed 0` |
| рецепт | как у бейзлайна на CE: 100 эпох, lr 0.1, wd 5e-4, warmup 1, батч 128 |

**Два запуска на точку.** Разница между соседними точками сетки сравнима с разбросом
между сидами. С одним запуском выбор был бы почти случайным.

**Цель** — `top1`/`val` финальных моделей, среднее по запускам точки. Test в выборе
не участвует. При близких значениях смотрим `val/ce` и `val/kl`.

**Кэш учителя** не зависит от α и T: его строит первая подзадача (~25 мин на 100 эпох),
остальные используют готовый. `--seed`, батч и `--split_seed` совпадают с бейзлайном —
иначе кэш пересчитается, а сравнение с CE станет некорректным.

## Запуск

1. В Colab — `colab/agent.ipynb` (агент на очереди `colab-t4`).
2. Контроллер — локально (Mac) или ячейкой Colab:
   ```bash
   python scripts/kd_grid.py --queue colab-t4
   ```
   Smoke: `--alphas 0.5 0.9 --temperatures 4 --num_train_epochs 2`.

Время: ~25 мин на кэш один раз; точка ≈ 7 мин обучения + 1–2 мин подготовки агента;
9 точек ≈ 1.3 ч.

## Результат

- **Сравнение в UI:** у контроллера во вкладке подзадач выделить точки → Compare
  (кривые `top1`/`ce`/`kl` по train и val, single values, параметры).
- **Таблица точек** (строка — точка; α, T, `val/top1`, `val/top1_std`, `val/ce`,
  `val/kl`, train-метрики): артефакт `results` контроллера и
  `<output_dir>/kd-grid-w32-c2.csv`.
- **Сырые данные каждой точки** — в `<output_dir>/<task_id подзадачи>/`
  (формат — `docs/metrics.md`).

*Результаты сетки заполняются после запуска.*
